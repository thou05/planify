# Planify — Project Documentation

Bộ tài liệu nền tảng để phát triển hệ thống quản lý công việc Planify.

## Documents

- [PROJECT_OVERVIEW.md](./PROJECT_OVERVIEW.md) — Tổng quan hệ thống, kiến trúc và công nghệ.
- [USE_CASES.md](./USE_CASES.md) — Danh mục và đặc tả Use Case.
- [REQUIREMENTS.md](./REQUIREMENTS.md) — Yêu cầu chức năng, phi chức năng và quy tắc nghiệp vụ.
- [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md) — Design System Glassmorphism và color tokens.

## Tech Stack

- Frontend: Next.js
- Backend: NestJS
- Database: Supabase / PostgreSQL
- Realtime: Socket.IO
- Cache: Redis
- AI: LLM API
- Testing: Jest + Playwright
